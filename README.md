# GoogleChromeExtensions

## AI & Assistant

2. [Claude](https://chromewebstore.google.com/detail/claude/fcoeoabgfenejglbffodgkkbkcdhcgfn) - *Claude in Chrome: interact with webpages using Claude in the browser side panel.*
3. [Claude Arabic RTL Switcher](https://chromewebstore.google.com/detail/claude-arabic-rtl-switche/maflbcmabkjalhnpjmamiajfdknldcdo) - *Switches Arabic Claude responses to right-to-left rendering.*
